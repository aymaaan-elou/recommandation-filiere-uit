# 🎓 Système de Recommandation de Filière - UIT

Application web qui recommande la filière universitaire la plus adaptée aux nouveaux bacheliers de la Faculté des Sciences de Kénitra.

## Fonctionnalités

- 18 filières de la faculté prises en compte
- Recommandation par similarité cosinus
- Justification personnalisée des recommandations
- Classement complet des filières

## Technologies

- Python 3.11
- Streamlit
- scikit-learn
- pandas / numpy
